# dotfiles

## Setup

```bash
git clone git@github.com:gs1068/dotfiles.git ~/repositories/dotfiles
cd ~/repositories/dotfiles
./install.sh
```

## macOS: Homebrew packages

```bash
./scripts/brew.sh
```

## Powerlevel10k

フォントをインストールする

https://github.com/romkatv/powerlevel10k#manual-font-installation

```zsh
p10k configure
```
